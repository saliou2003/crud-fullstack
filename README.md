# Application Full-Stack : Gestion de Commandes (Spring Boot + Angular)

Projet personnel développé pour consolider mes compétences en architecture **Full-Stack**, **DevOps** et intégration continue.

## 🚀 Fonctionnalités
- **Back-end :** API REST sécurisée avec **Spring Boot**, JPA, MySQL et authentification **JWT** (gestion des rôles Admin/Membre).
- **Front-end :** Interface utilisateur moderne sous **Angular** (Routing, Intercepteurs, Guards).
- **DevOps & CI/CD :** 
  - Conteneurisation avec **Docker** et **Docker Compose**.
  - Pipeline d'intégration continue automatisé via **GitHub Actions** (compilations, tests et images Docker).

## 🛠️ Stack Technique
- **Back-end :** Java, Spring Boot, Spring Security, Maven, MySQL
- **Front-end :** TypeScript, Angular, HTML5/CSS3, Bootstrap
- **DevOps :** Linux, Git/GitHub, GitHub Actions, Docker, Docker Compose
